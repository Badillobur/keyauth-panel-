📡 Endpoint Base

Todos los requests son POST con Content-Type: application/x-www-form-urlencoded. El campo type determina la accion.

📦 Formato de Respuesta
{"success": true | false, "message": "descripcion", ...datos}
⚡ Endpoints
POST?type=init
Inicializar sesion. Siempre llamar primero.
CampoDescripcion
nameREQNombre de la app
owneridREQOwner ID
verREQVersion del cliente
POST?type=login
Login con usuario y contraseña.
CampoDescripcion
sessionidREQID de sesion del init
usernameREQNombre de usuario
passREQContraseña
hwidOPTHardware ID
POST?type=register
Registro de nuevo usuario con key.
CampoDescripcion
sessionidREQID sesion
usernameREQUsuario
passREQContraseña
keyREQLicencia de activacion
emailOPTEmail
POST?type=license
Activar acceso solo con key (sin usuario).
CampoDescripcion
sessionidREQID sesion
keyREQLicencia
POST?type=check
Verificar que la sesion sigue activa.
POST?type=var &varid=nombre
Obtener valor de variable remota.
POST?type=log &message=texto
Guardar log desde el cliente.
💻 Código C++ de Ejemplo
Integracion completa con LMAx27
// En Kaflow.hpp:
std::string name    = XorStr("TuAppName").c_str();
std::string ownerid = XorStr("TuOwnerId").c_str();
std::string secret  = XorStr("TuSecret").c_str();
std::string version = XorStr("1.0").c_str();
std::string url     = XorStr("https://tu-servidor.onrender.com/api/1.2/").c_str();
api KeyAuthApp(name, ownerid, secret, version, url);

// En WinMain.hpp - antes del init:
name    = XorStr("TuAppName").c_str();
ownerid = XorStr("TuOwnerId").c_str();
secret  = XorStr("TuSecret").c_str();
version = XorStr("1.0").c_str();
url     = XorStr("https://tu-servidor.onrender.com/api/1.2/").c_str();
KeyAuthApp.init();

// Login:
KeyAuthApp.login(username, password);
if (KeyAuthApp.response.success) {
    // acceso concedido
    std::string user = KeyAuthApp.user_data.username;
    // Iterar suscripciones:
    for (const auto& sub : KeyAuthApp.user_data.subscriptions) {
        if (sub.name == "Supreme" || sub.name == "default") { /* menu completo */ }
        if (sub.name == "Basico")  { /* menu basico */ }
    }
}

// Obtener variable remota:
std::string config = KeyAuthApp.var("mi_variable");
