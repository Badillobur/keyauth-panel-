📡 Endpoint Base

Todos los requests son POST con Content-Type: application/x-www-form-urlencoded o JSON. El campo type determina la accion a ejecutar.

📦 Formato de Respuesta
{
  "success": true | false,
  "message": "descripcion del resultado",
  // datos adicionales segun el endpoint
}
🚀 Endpoints Disponibles
POST /api/1.2/ ?type=init
Inicializa la sesion y verifica la version de la app. Siempre debe llamarse primero.
CampoTipoDescripcion
namestringREQNombre de la app
owneridstringREQID del owner (admin)
verstringREQVersion actual del cliente
// Respuesta exitosa
{
  "success": true,
  "sessionid": "AbCdEf...",
  "appinfo": { "numUsers": "42", "numOnlineUsers": "3", "numKeys": "100", "version": "1.0" }
}
POST /api/1.2/ ?type=login
Autentica un usuario con usuario y contraseña. Requiere sesion inicializada.
CampoTipoDescripcion
sessionidstringREQID de sesion del init
usernamestringREQNombre de usuario
passstringREQContraseña
hwidstringOPTHardware ID del equipo
namestringREQNombre de la app
owneridstringREQOwner ID
POST /api/1.2/ ?type=register
Registra un nuevo usuario usando una licencia/key.
CampoTipoDescripcion
sessionidstringREQID de sesion
usernamestringREQUsuario a crear
passstringREQContraseña
keystringREQLicencia de activacion
emailstringOPTEmail
hwidstringOPTHardware ID
POST /api/1.2/ ?type=license
Activa acceso usando solo una key (sin usuario/contraseña).
CampoTipoDescripcion
sessionidstringREQID de sesion
keystringREQLicencia
hwidstringOPTHardware ID
POST /api/1.2/ ?type=check
Verifica que la sesion actual sigue siendo valida.
POST /api/1.2/ ?type=var
Obtiene el valor de una variable de la aplicacion.
CampoDescripcion
varidREQNombre de la variable
💻 Codigo C++ de Ejemplo
Integracion completa
#include "Auth/Auth.hpp"
#include "Auth/Encrypter.hpp"

// Inicializa con tus credenciales del panel
KeyAuth::api KeyAuthApp(
    XorStr("NombreDeTuApp"),
    XorStr("tu-owner-id"),
    XorStr("tu-secret"),
    XorStr("1.0"),
    XorStr("http://tu-servidor.com/api/1.2/")
);

int main() {
    // 1. Inicializar - siempre primero
    KeyAuthApp.init();
    if (!KeyAuthApp.response.success) {
        MessageBoxA(0, KeyAuthApp.response.message.c_str(), "Error", MB_ICONERROR);
        exit(1);
    }

    // 2. Login con usuario y contraseña
    std::string user, pass;
    std::cout << "Usuario: "; std::cin >> user;
    std::cout << "Password: "; std::cin >> pass;

    KeyAuthApp.login(user, pass);
    if (!KeyAuthApp.response.success) {
        MessageBoxA(0, KeyAuthApp.response.message.c_str(), "Login Failed", MB_ICONERROR);
        exit(1);
    }

    // ----- O solo con key (sin registro) -----
    // KeyAuthApp.license("KEY-XXXXX-XXXXX-XXXXX-XXXXX");

    // 3. Verificar sesion periodicamente
    KeyAuthApp.check();

    // 4. Obtener variable remota
    std::string config = KeyAuthApp.var("mi_variable");

    // 5. Info del usuario
    std::string username = KeyAuthApp.user_data.username;
    std::string hwid     = KeyAuthApp.user_data.hwid;

    return 0;
}
